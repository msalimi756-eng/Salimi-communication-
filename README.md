# Salimi Communication — Android APK Project

یہ Android Studio project ہے۔ APK بنانے کے لیے Android Studio میں project کھولیں اور:
Build → Build APK(s)

اہم:
- یہ ورژن موبائل کے لیے بنایا گیا ہے۔
- حساب کا بنیادی ڈیٹا فون کے Local Storage میں محفوظ ہوتا ہے۔
- اس ورژن میں Cloud automatic sync شامل نہیں ہے۔
- اصل APK اسی project کو Android Studio/Gradle سے build کرنے کے بعد بنے گا۔
